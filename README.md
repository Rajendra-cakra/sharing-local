# Tujuan Pembuatan
Tujuan dari dibuatnya software ini adalah:
kita biasanya ingin menyalin suatu chat/pesan/text dari hp ke laptop. apabila menggunakan sosmed, memakan wakatu yang lama. dengan software ini, anda bisa langsung berkirim pesan dengan cepat dan aman.

selain itu, kita biasanya transfer file dengan cara yang tergolong ribet. misalnya pakai kabel, software sharing lain, atau sosmed. lama! dengan software ini, anda tidak perlu internet, cepat, tinggal run, scan, upload, selesai.

# sharing-local
website sharing file dan chat secara realtime, cepat, dan tanpa internet. hanya menggunakan jaringan yang sama (local)

# cara kerja
run server.py, lalu scan kode qr, dan jadi! anda bisa mengirim pesan, upload file, dan lainnya
